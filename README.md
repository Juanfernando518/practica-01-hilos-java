# Instrucciones de Ejecución

1. **Clonar el repositorio:**

  https://github.com/Juanfernando518/practica-01-hilos-java.git

Asegúrate de que los archivos AnalizadorTexto.java y quijote.txt estén en la misma carpeta, y ejecuta:

**javac AnalizadorTexto.java**
